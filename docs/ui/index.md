# Virentia UI

Virentia UI connects model state to DOM. A component describes its display once; store changes update existing text and properties.

Follow the [tutorial](./learn/) from a first button to a list of counters. Use the [guides](./guides/) for model ownership, DOM and SSR, or the [API reference](./api/) for signatures and parameters.

Start with [environment setup](./installation), or go to [your first component](./learn/first-app).
