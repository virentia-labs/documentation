# Recipes

Complete scenarios built on native models. Read the learning chapters first if model, display and structural range are still unfamiliar.

- [Conditional editor](./conditional-editor): preserved draft, fresh DOM.
- [Model list](./model-list): root-created children and direct movement.
- [Async search](./async-search): explicit external-await boundary and stale-result cancellation.
- [SSR](./ssr): request/client scopes, load and hydration.
- [Parallel tests](./testing): shared static definitions without global resets.

Maintained example sources are type-checked against current UI code. No reactivity compiler, hooks or reconciliation is used.
