# Tutorial

Build a counter, then turn it into a list of independent counters. Each chapter adds one capability to the same example.

You need HTML, JavaScript and basic JSX familiarity. [Prepare your environment](../installation), then follow the chapters in order.

1. [Your first component](./first-app)
2. [State](./state-and-props)
3. [Events](./events)
4. [Derived values](./derived)
5. [Props](./props)
6. [Conditional rendering](./conditions)
7. [A list of counters](./model-lists)

Each walkthrough changes the code and its connection diagram together. A small task lets you check what you learned.

After the basics, choose a [guide](../guides/) for your task. Find complete signatures in the [API reference](../api/).
