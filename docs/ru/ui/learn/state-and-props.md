# Состояние

Добавим в модель поле `count` с начальным значением `0`. `f.number(0)` описывает числовое поле; `self.model.count` даёт доступ к его стору в отображаемом экземпляре.

<UIWalkthrough kind="state" />

`f` импортируется из `@virentia/core/models`. В JSX передаётся сам стор: `{self.model.count}`. Рендер подключает к нему текст кнопки.

Не заменяйте его на `count.value`: это прочитает число в момент создания view, а не создаст привязку. Читать и менять `.value` будем в коде действий.

Поменяйте начальное значение на `10`: теперь кнопка показывает `10`. На клики она пока не реагирует — добавим действие в следующей главе.
