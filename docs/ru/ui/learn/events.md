# События

Научим кнопку увеличивать число. Действие `increment` объявляется в модели через `action`, затем передаётся в `onClick`.

<UIWalkthrough kind="events" />

`action` импортируется из `@virentia/ui`. Он объединяет событие и реакцию: при вызове выполняется обработчик, который меняет `count.value`.

`setup` объявляет юниты модели. Возвращённый `increment` доступен в view как `self.model.increment`.

Нажмите кнопку несколько раз. Число меняется в существующей кнопке; `view` повторно не вызывается.

Добавьте по тому же образцу действие `decrement` и вторую кнопку. Для этого не нужно менять код рендера.
