# Вычисления

Покажем удвоенное значение счётчика. Вместо отдельного изменяемого поля объявим `computed`, зависящий от `count`.

<UIWalkthrough kind="derived" />

`computed` импортируется из `@virentia/ui`. Его функция читает `count.value`; Core отслеживает эту зависимость. В view передаётся готовый стор `doubled`.

Теперь один клик обновляет два текста: число на кнопке и результат удвоения. Ни один обработчик не должен вручную записывать `doubled`.

Замените удвоение на квадрат числа. Меняется только вычисление в модели, не код view.
