# Условный вывод

Добавим кнопку Details, скрывающую удвоенное значение. Число счётчика при этом должно сохраниться.

В модель добавьте `expanded: f.boolean(true)` и действие переключения:

```ts
const toggle = action(() => {
  self.expanded.value = !self.expanded.value;
});
return { increment, doubled, toggle };
```

Условие, которое должно реагировать на изменения, выделяется в функцию внутри view:

<UIWalkthrough kind="condition" />

В JSX передаётся `{details}`, не результат `details()`. Рендер сам вызывает функцию и отслеживает чтение `expanded.value`.

При скрытии удаляется только `output`. Кнопка счётчика остаётся на месте. При показе создаётся новый `output` с текущим результатом — старое и новое поддерево не сравниваются.

Скройте подробности, увеличьте число и покажите их снова. Результат должен учитывать все клики.
