# Учебник

Соберём счётчик и постепенно превратим его в список независимых счётчиков. Каждый шаг добавляет одну возможность к тому же примеру.

Нужны HTML, JavaScript и базовое знакомство с JSX. [Подготовьте окружение](../installation), затем проходите главы по порядку.

1. [Первый компонент](./first-app)
2. [Состояние](./state-and-props)
3. [События](./events)
4. [Вычисления](./derived)
5. [Пропсы](./props)
6. [Условный вывод](./conditions)
7. [Список счётчиков](./model-lists)

В пошаговых блоках меняются код и схема связей. После объяснения есть небольшая задача для проверки.

Закончив основы, выбирайте [руководства](../guides/) по своей задаче. Полные сигнатуры находятся в [API](../api/).
