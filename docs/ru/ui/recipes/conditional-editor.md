# Условный редактор с сохранённым черновиком

Создайте модель редактора в родительской children-связи до DOM. Переключайте только его отображение. Тогда скрытие не уничтожает draft, а повторное открытие создаёт свежий input с прежним значением модели.

[Как передать готовую модель](../learn/setup-and-view).

В модели учебного примера Board владеет Task; Task хранит draft и ref. View редактора получает готовую Task-модель. Она показывается вместо списка, не одновременно со второй view того же Task.

Изменение editorOpen повторяет только функцию участка. Unmounted завершается до удаления input, ref становится null. Черновик жив, пока Task принадлежит Board. Keep здесь не требуется.

Сохранять DOM-only ввод при пересоздании участка библиотека не обещает: переносите его в модель через input action. [Правила lifecycle](../api/refs-events).
