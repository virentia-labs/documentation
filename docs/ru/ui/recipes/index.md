# Рецепты

Каждый рецепт собирает законченный сценарий поверх нативной модели. Начните с базовых глав, если ещё не различаете модель, отображение и структурный участок.

- [Условный редактор](./conditional-editor) — сохраняемый черновик и новый DOM.
- [Список моделей](./model-list) — родитель создаёт и перемещает дочерние экземпляры.
- [Асинхронный поиск](./async-search) — явная граница внешнего await и отмена устаревшего результата.
- [SSR](./ssr) — отдельные scope запроса и клиента, load и hydration.
- [Параллельные тесты](./testing) — общий staticModel без глобальных очисток.

Исходники в каталоге examples проверяются TypeScript против текущего кода UI. Рецепты не используют UI-компилятор, хуки или reconciliation.
