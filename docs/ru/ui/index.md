# Virentia UI

Virentia UI связывает состояние модели с DOM. Компонент описывает отображение один раз; изменения сторов обновляют его текст и свойства.

[Учебник](./learn/) проведёт от первой кнопки до списка счётчиков. [Руководства](./guides/) помогут с владением моделями, DOM и SSR. [API](./api/) содержит сигнатуры и параметры.

Начните с [подготовки окружения](./installation) или сразу с [первого компонента](./learn/first-app).
